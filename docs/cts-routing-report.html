本轮已实现

  • 严格主时钟 SDC：period、waveform、transition、uncertainty 与明确的约束作用域。
  • 预留引脚接入、固定 VIA、带障碍的有界 CPU 布线和版本 5 路由快照。
  • 真实 PDK 标称 OpenRCX 提取与详细 SPEF 传递。
  • 传播时钟、完整重算 / 无修改更新一致性及独立 OpenSTA 比较。

验证保持分层

  • OpenDB / KLayout 独立检查连通、部分间距、阻挡和短接。
  • 原始 GDS 继续验证 tap 与井 / 衬底接触。
  • 每套工艺 CEC 与 512 组仿真向量，含流水线历史值检查。
  • 8 个时序端点全部受约束，未约束端点为 0。
反例确实会失败

移除一条网络的路由、引入电源短接、删除 SPEF 标注和给一条时钟分支增加 10,000 倍电阻，都会触发对应检查失败。重复布线的 DEF 哈希一致；失败的命令不改变原工作区 HEAD，重新放置会使旧路由失效。

边界与下一步

布线器采用有限坐标网格与显式工作预算。四寄存器样例通过；较密集的六寄存器样例仍可能触发引脚接入或搜索预算，不能据此宣称工业规模能力。RC 提取目前由外部 OpenRCX 完成，原生校准 RC 提取器尚未实现。

GF180 的技术 LEF 明确提示其寄生值不适用于提取，本轮采用 PDK 专用规则文件。完整 DRC、天线、LVS、IR/EM、GDS streamout 均未签核。后续优先核查 STA 差异与 hold 修复，再改进密集引脚接入、布局与布线优化。
