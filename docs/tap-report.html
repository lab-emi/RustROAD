原始 GDS / KLayout：接触确实存在

用 nwell、掺杂、活性区、contact 与金属多边形核查：Sky130 的 licon → li1 → mcon → met1；GF180 的 Contact → Metal1。

RustSys → RustROAD → RustSTA

真实库函数的 Yosys 证明、原 RTL 对导出网表的等价检查、每套工艺 512 组 Verilator 仿真均通过。时钟树通过独立 OpenDB sink-to-driver 追踪，覆盖全部六个 sink 与新 buffer。

  • sky130：RustSTA/OpenSTA 最大差值 6.029404e-07 ns；24 个含输入的逻辑/时钟单元纳入 GDS 活性区检查。
  • gf180：RustSTA/OpenSTA 最大差值 8.695038e-07 ns；28 个含输入的逻辑/时钟单元纳入 GDS 活性区检查。

时序为 TT、理想时钟、理想线网，容差 0.001 ns。14 个约束端点与 2 个常量驱动、无数据到达的 D 引脚按真实结果保留。脉宽 / 最小周期限制仍有显式诊断。增量检查仅验证无修改更新，不代表完成 ECO 或提取后时序。

规则依据、资源和复现

Sky130 的 nwell.4 描述井接触要求；GF180 有 条件化闩锁规则与 DF.13/14 距离规则。当前检查不涵盖所有标记、深井、I/O guard ring、enclosure 或可靠性规则。

完整验证耗时 0:16.56；最大宿主进程 RSS 403,524 KiB。包含综合、导入、tap / clock 插入、重复放置、导出、仿真、GDS、OpenDB 和 STA。小设计功能基线不代表大规模吞吐量。
